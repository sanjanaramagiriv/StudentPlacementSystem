# Student Placement Analysis System

## Project Description
The Student Placement Analysis System is a web-based application developed to analyze student performance and placement eligibility.

It helps colleges evaluate students based on academic performance, aptitude, technical skills, and communication skills.

## Features
- Student performance analysis
- View total number of students
- Track placed and unplaced students
- Calculate placement percentage
- Analyze student skills
- Add student details
- Placement eligibility prediction

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript

## How to Run
1. Install Python.
2. Install Flask:
   `pip install flask`
3. Run the application:
   `python app.py`
4. Open the local URL displayed in the terminal.

## Project Purpose
To help educational institutions analyze student performance and improve placement preparation through data-driven insights.
